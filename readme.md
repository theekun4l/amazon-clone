# 🛒 Amazon Website Clone

A frontend practice project inspired by the Amazon website, built using **HTML and CSS**.

This project was created to practice website layout, Flexbox, styling, spacing, images, navigation bars, and footer design.

## 🚀 Features

- Amazon-style navigation bar
- Search bar with category selector
- Delivery location section
- Account & Orders section
- Shopping cart section
- Secondary navigation menu
- Product/category cards
- Flexbox-based layout
- Footer with multiple link sections
- Bottom footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📚 What I Practiced

- Flexbox
- `flex-wrap`
- `justify-content`
- `align-items`
- `gap`
- CSS backgrounds
- Borders and border-radius
- Box shadows
- Hover effects
- Basic semantic HTML
- Website layout and positioning

## 🎯 Purpose

This project was built as a **learning/practice project** to improve my HTML and CSS skills by recreating the general structure and layout of an e-commerce website.

It is **not an exact or production-ready clone** of Amazon.
